abstract: We present EditoriaLLM, a web application that uses large language models
  to generate competitive programming editorials from problem statements, reference
  solutions, algorithmic tags, audience settings, and style templates. This approach
  streamlines using a general-purpose chat interface into a simple, all-in-one tool,
  tailored to our particular use-case. EditoriaLLM is designed as a human-in-the-loop
  assistant for competitive programming education, with early adoption already observed
  in national competition contexts.
